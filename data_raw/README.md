# Raw images

The images are not redistributed in this repository.

1. Download the Tomatoes dataset (Enalis, 2023, CC0: Public Domain): https://www.kaggle.com/datasets/enalis/tomatoes-dataset
2. Place it at `data_raw/Tomatoes Dataset/`, or set `TOMATO_DATA_ROOT` to its location.
3. Keep the publisher's partition, with `train/` and `val/` and one folder per class: `Damaged`, `Old`, `Ripe`, `Unripe`.
